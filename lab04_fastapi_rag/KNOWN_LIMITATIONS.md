# 已知限制

## 文档与检索范围

- 知识库固定为FastAPI `0.136.3`、Commit
  `82064857539e6286522c347b4b11331b48dd2378`下的102页中文学习文档。
- 不使用英文文档、互联网搜索或机器翻译兜底。固定Commit之后新增或修改的FastAPI
  内容不在回答范围内。
- NumPy索引对400个Chunk做全量精确检索，适合教学规模，不代表生产级大规模检索
  方案。
- Chunk以标题和相邻小节为边界。19个不可拆分代码块超过800估算Token，59个文档
  尾部或短文档Chunk低于500估算Token。
- 文档审计保留1个无法解析的内部链接警告；它不影响268个代码依赖的完整性。

## 模型与运行环境

- Qwen3-Embedding-0.6B权重约1.19GB，首次下载速度取决于Hugging Face网络链路。
  CPU构建400条向量的实测耗时约911秒。
- 在线回答依赖阿里云百炼网络与账号。正式`attempt_001`中有2题因连接失败而没有
  有效答案；正式题不会通过自动重试掩盖这一事实。
- JSON Mode保证返回JSON对象，但不保证内容一定通过业务校验。正式运行有1题因
  包含禁止的HTML而进入`validation_failed`。
- 动态长度采用方案A，不发送固定输出Token上限，以降低JSON截断风险；这不等于
  输出长度、耗时或调用成本没有波动。

## 门控、回答与评价

- 门控阈值`0.6831968426704407`只由冻结校准集确定，没有根据30道正式题回调。
  它不能代表所有FastAPI问题的通用最优阈值。
- 边界题6/6得到正确拒答，但只有2/6使用预期的`model_refused`机制，其余4题在
  检索门控阶段被拒绝。
- 正式18道知识库内题中，15题产生有效答案；Codex Judge给出12题
  `fully_correct`、3题`mostly_correct`。无有效答案的3题仍计入回答率分母。
- Codex Judge是一次性外部盲审，不是绝对真值。它不自动复审、仲裁或重试；正式
  指标只使用`attempt_001`。
- 回答仅允许引用本次Top-k Chunk。严格证据边界能降低无依据扩展，但也可能使回答
  比通用聊天模型更保守。

## 产品边界

- Streamlit是本地单用户教学界面，不包含身份认证、数据库、云部署、并发任务队列
  或生产级审计。
- 每个问题独立处理；最近10条结果只存在当前Streamlit会话中，不参与后续问题。
- 页面不会自动下载文档、模型或重建索引。前置产物缺失时必须回到对应CLI步骤。
- 用户代码只作为文本解析和检索，不会执行。
- 模型输出具有波动性。公开示例只代表一次真实冻结运行，不应被理解为模型的固定
  输出或普遍性能结论。
