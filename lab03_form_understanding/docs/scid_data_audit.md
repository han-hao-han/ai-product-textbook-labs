## 数据内容

官方论文和数据页说明：

- 数据集包含40,716张真实扫描中文票据；
- 票据来自6个类型：
  - 飞机行程单；
  - 出租车发票；
  - 通用定额发票；
  - 火车票；
  - 通行费发票；
  - 客运发票；
- 官方划分为训练集19,999张、验证集10,358张、测试集10,359张；
- 提供155,497对结构化字段标注；
- 提供979,309个OCR文本框；
- 预设10类可抽取字段，不同票据类型使用其中不同子集。

SCID属于预设字段的中文票据信息抽取数据，不是XFUND式开放
question-answer关系表单。若正式采用，需要修改实验名称、Prompt、
字段集合、参考结果转换和比较说明。

## 隐私审计

官方论文说明：

- 数据来自经企业法务和财务部门审核、授权的历史非敏感票据；
- 姓名、身份证号、车牌号等个人隐私信息经过人工脱敏；
- 结构化标注字段排除了可能涉及个人信息的字段。

这些是支持SCID进入候选的有力证据，但仍属于发布方说明。
由于本轮没有取得原始数据，尚未完成：

- 对实际图片进行身份证号模式扫描；
- 检查脱敏区域是否仍可恢复或推断；
- 检查姓名、乘车信息、行程信息、发票号码和票据代码的组合风险；
- 检查OCR标注是否保留了图像中已经遮挡的信息；
- 对主样本、观察样本和验证样本逐张人工确认。

正式准入的最低隐私规则（2026-07-23 按用户确认更新）：

```text
身份证号不得出现
姓名允许出现，不作为排除条件
手机号、邮箱、地址、账户、车牌号等其他信息需要记录和人工复核，但不自动排除
自动扫描未命中不代表原图无身份证号
正式样本必须逐张检查原图和标注
若原图存在遮挡，必须人工确认身份证号不可恢复或推断
```

## 标注质量审计

SCID提供两类标注：

- 结构化信息：每张图像对应的预设Key-Value字段；
- OCR信息：文字内容和文本框位置。

论文说明两个流程均先生成伪标签，再由标注人员复核清洗：

- 结构化字段全部经过人工复核；
- 人眼无法识别的模糊文字标为`NOT CARE`；
- OCR背景文字可能仍含噪声；
- 关键字段相关OCR标注经过人工复核和补全。

因此，SCID的结构化字段比XFUND显式关系更接近本实验所需的参考答案，
但仍不能直接假设零错误。正式采用后必须增加：

```text
原始数据集标注
→ 本地转换结果
→ 人工复核状态
→ 人工校正记录
→ 最终人工标注参考结果
```

不得静默修改原始标注，也不得让模型判断参考标注是否正确。

## 教学适配性

### 优点

- 真实中文扫描数据；
- 发布方明确实施人工脱敏；
- 结构化任务边界清晰；
- 具有打印错位、模糊、重叠、印章干扰等真实难例；
- 提供字段级参考标注；
- 适合展示视觉模型、Schema、确定性比较和错误分析。

### 代价

- 数据访问需要人工申请；
- 原始数据较大；
- 原图许可边界需要进一步确认；
- 场景从通用表单收窄为中文票据；
- 字段为预设类别，不再是任意question-answer关系；
- 票据号码、时间和路线等字段虽然不一定属于直接身份信息，仍需组合风险复核。
