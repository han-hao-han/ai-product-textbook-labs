# H3比较规则v2

## 修订原因

用户人工检查发现：

- XFUND原始显式question-answer关系存在少许错误；
- 模型结果与数据集标注不一致时，不能默认模型更差；
- `☑`、`□`等特殊符号具有版面语义，不能自动删除或改写；
- 原有“值错误”“遗漏”“额外字段”等名称容易让读者误以为XFUND标注是绝对正确答案。

因此需要区分：

```text
与数据集原始标注是否一致
与原图内容是否一致
```

## 第一层：数据集原始标注一致性

这一层由程序确定性完成，不判断谁更正确。

建议状态：

```text
exact_match
normalized_match
different_value
different_pairing
not_in_model_output
not_in_dataset_annotation
```

读者界面统一表述：

| 状态 | 建议中文 |
|---|---|
| `exact_match` | 与数据集原始标注完全一致 |
| `normalized_match` | 保守规范化后与数据集原始标注一致 |
| `different_value` | 与数据集原始标注的值不同 |
| `different_pairing` | 键值关系与数据集原始标注不同 |
| `not_in_model_output` | 数据集原始标注字段未出现在模型输出中 |
| `not_in_dataset_annotation` | 模型字段未出现在数据集原始标注中 |

这一层的指标只能称为：

```text
数据集原始标注一致率
```

不得称为：

```text
模型准确率
识别正确率
人工标注参考结果正确率
```

## 第二层：人工原图裁决

人工结合原图检查第一层的不一致项。

程序可以为人工复核提供以下确定性提示，但提示本身不计为正确：

```text
reference_value_contained_in_model_value
model_value_contained_in_reference_value
same_value_different_key
checkbox_symbol_difference
same_key_multiple_dataset_values_combined
high_key_similarity
high_value_similarity
```

例如，模型在某个值后附带了日期或签名信息时，程序可以提示“模型值包含数据集标注值及额外文本”，而不是直接写成“值错误”；但是否属于合理合并、键值错配或模型错误，仍由人工看原图裁决。

其中：

- “同键多行可能被模型合并”只在多个同名数据集值按顺序拼接后与一个模型值一致时提示；
- 字段名或字段值相似度使用确定性的字符序列比率，阈值为`0.75`；
- 相似度和包含关系只是定位复核项的线索，不参与第一层一致率，也不直接参与最终正确率。

建议裁决状态：

```text
model_supported_by_image
dataset_annotation_supported_by_image
both_acceptable
both_incorrect
uncertain
```

对应含义：

| 状态 | 含义 |
|---|---|
| `model_supported_by_image` | 原图支持模型结果，数据集原始标注需要校正 |
| `dataset_annotation_supported_by_image` | 原图支持数据集标注 |
| `both_acceptable` | 两种表达均能被原图支持 |
| `both_incorrect` | 两者均需校正 |
| `uncertain` | 原图不足以可靠裁决 |

人工裁决必须记录理由和证据，不得由模型自己生成。

## 第三层：最终人工复核参考结果

只有完成逐字段复核后，才形成：

```text
最终人工标注参考结果
```

来源必须可追踪：

```text
XFUND原始显式关系
＋人工确认
＋显式校正记录
```

只有这一层才可用于计算：

```text
参考字段识别正确率
```

未完成复核的样本不计算该指标。

## 匹配严格程度

建议保留当前保守确定性规范化，不增加：

- 模糊字符串相似度自动判对；
- 大模型评分；
- 同义词自动等价；
- `☑`、`□`自动语义转换；
- 日期和数值的宽松语义换算。

“降低严苛感”的方式不是偷偷放宽规则，而是：

1. 将第一层结果改称“一致/不一致”；
2. 不再把所有不一致称为模型错误；
3. 增加人工原图裁决；
4. 单独形成经过复核的最终参考结果。
