# XFUND特殊符号处理策略

## 当前发现

对拟定的10张教学样本进行只输出计数的本地检查后，发现5张样本的answer实体包含`☑`或`□`。

这些符号可能表示：

- 选中或未选中；
- 多选项状态；
- 版面中的空框；
- OCR或标注人员对复选框外观的转写。

仅凭字符本身不能可靠决定其语义。

## 当前程序行为

- XFUND参考结果转换器原样保留符号；
- 保守文本规范化不会删除或互换这些符号；
- 确定性比较要求符号一致，否则不会自动判为正确；
- Prompt v1只要求保持原文，没有单独规定复选框的语义输出。

## 冻结规则

```text
原始标注层：原样保留
自动规范化层：不转换
人工复核层：结合原图判断
人工校正层：保存有理由、有证据的显式校正
比较层：只使用通过人工确认或校正后的最终参考结果
```

在H3重新确认前，不修改Prompt v1，不新增“☑=是、□=否”等自动规则。
