## 边界

- 仓库只保留三个 QMSum 转换样例：TS3010a、IS1003a、ES2011a。
- 不默认提交完整真实数据集。
- Streamlit 提供完整 QMSum 本地下载入口，下载结果写入 Git 忽略目录 `data/downloads/qmsum_full/`。
- 不默认把真实数据输出作为教材主实验结论。
- 除 TS3010a 外，其他仓库样例和完整数据集样例默认没有人工金标准，只能做结构化抽取和证据校验。
- 真实数据可能包含公开会议发言，截图和教材材料需要最小展示。
